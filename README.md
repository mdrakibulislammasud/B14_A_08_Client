# Neighbourly – Community Events Platform

**Live Website:** https://neighbourly-client.vercel.app

Neighbourly is a community-driven event management platform where people can discover, create, join, and manage social development events in their local communities.

## Features

- **User Authentication:** Register and log in using email and password or Google authentication.
- **Browse Events:** Explore available social development events.
- **Create Events:** Create and publish community events.
- **Event Details:** View detailed information about individual events.
- **Join Events:** Participate in events organized by the community.
- **Joined Events:** View events you have joined.
- **Responsive Design:** Access the platform from desktop, tablet, and mobile devices.

## Technology Stack

- Next.js
- React
- Tailwind CSS
- DaisyUI
- Better Auth
- MongoDB
- React Hot Toast

## Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/mdrakibulislammasud/B14_A_08_Client.git
```

### 2. Navigate to the project directory

```bash
cd B14_A_08_Client
```

### 3. Install dependencies

```bash
npm install
```

### 4. Configure environment variables

Create a `.env.local` file in the project root:

```env
NEXT_PUBLIC_API_URL=https://neighbourly-server-black.vercel.app
```

### 5. Run the development server

```bash
npm run dev
```

Open http://localhost:3000 in your browser.

## Available Scripts
